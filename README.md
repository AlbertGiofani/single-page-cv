# single-page-cv
A single-page CV built with HTML

## Project Description

This project is a simple single-page CV that presents personal information, skills, education, and work experience.

## Technologies Used

- HTML5
- Semantic HTML

## How to Run

1. Clone this repository:
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation or dependencies are required.
